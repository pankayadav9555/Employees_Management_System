# 👨‍💼 Employee Management System

A full-stack Employee Management System built using **React, Spring Boot, REST API, and MySQL**.

The application allows users to efficiently manage employee records with complete CRUD functionality, search, department filtering, and salary statistics.

## ✨ Features

- ➕ Add new employees
- 📋 View all employees
- ✏️ Update employee details
- 🗑️ Delete employees
- 🔍 Search employees
- 🏢 Filter employees by department
- 💰 Calculate average salary
- 💵 Display highest salary
- 👥 Display total employees
- 🏢 Display total departments
- 📱 Responsive user interface
- 🔗 REST API integration
- 🌐 Production deployment
